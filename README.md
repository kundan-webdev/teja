## 🧱 Folder Structure

```

teja-website/
│
├── public/
│   └── assets/
│
├── src/
│   ├── components/
│   │   ├── common/     → reusable UI
│   │   ├── layout/     → navbar/footer/layout
│   │   └── sections/   → page sections
│   │
│   ├── pages/          → route pages
│   ├── hooks/          → custom hooks
│   ├── utils/          → constants/helpers
│   │
│   ├── styles.css
│   ├── App.jsx
│   ├── router.jsx
│   └── main.jsx

## 🧠 Architecture Philosophy

### 🔹 Component Driven

```

Page
├── Sections
├── Common Components

````

- Pages = route level
- Sections = layout blocks
- Common = reusable UI

---

### 🔹 Styling Strategy

- Tailwind utilities first
- Global patterns in `styles.css`
- Consistent spacing system
- Reusable component classes

## 🚀 Getting Started

### 1️⃣ Clone Repository

```bash
git clone https://github.com/kundan-webdev/teja.git
````

---

### 2️⃣ Install Dependencies

```bash
npm install
```

---

### 3️⃣ Start Development

```bash
npm run dev
```

Open:

```
http://localhost:5173
```

---

## 📜 Available Scripts

| Command         | Description      |
| --------------- | ---------------- |

| npm run lint    | Run ESLint       |

## 🧩 Development Rules

### Naming Convention

```
PascalCase → Components
camelCase → functions/hooks
UPPER_CASE → constants
```

---

### Component Rules

✔ Single responsibility
✔ Reusable logic
✔ Minimal props complexity
✔ Avoid large files
